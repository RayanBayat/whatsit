### Detailed description

```
Whatsit explains any word or phrase in the context of what you're actually reading — not a generic dictionary lookup.

HOW IT WORKS
1. Select any text on a page.
2. Right-click → "What's this?"
3. A chat card appears with a streamed explanation tuned to the surrounding content.

"Apple" in a recipe → the fruit. "Apple" in tech news → the company.

You can then ask follow-up questions in the same conversation thread, right on the page.

FULLY ON-DEVICE — ZERO DATA LEAVES YOUR MACHINE
The explanation is generated by Gemini Nano, the AI model built into Chrome 138+. Whatsit makes no network requests of its own. There is no backend, no account, no analytics, and no third-party services.

PERMISSIONS (AND WHY)
• contextMenus — adds the "What's this?" right-click item
• scripting + activeTab — injects the explanation card into the current tab only when you invoke it; no standing access to any website
• storage — remembers your prompt library and generation settings locally

REQUIREMENTS
• Chrome 138 or later (Gemini Nano must be available on your device)
• ~22 GB free disk space and 4 GB VRAM or 16 GB RAM for the first-time model download (performed by Chrome, not Whatsit)

PROMPT LIBRARY & SETTINGS
Click the toolbar icon to manage the on-device model download and switch active prompts. The Options page lets you edit your prompt library and tune generation settings (temperature, top-K, max length).
```

## Permission Justifications

| Permission | Justification |
|---|---|
| **contextMenus** | Adds the "What's this?" item to the right-click context menu — the only entry point into the extension. |
| **scripting** | Injects the explanation overlay into the active tab when the user invokes "What's this?" from the context menu. The script runs on demand per click only. |
| **activeTab** | Grants access to the current tab at the moment the user clicks "What's this?" — no standing access to any website. Access ends when the overlay is closed. |
| **storage** | Saves the user's prompt library and generation settings (temperature, top-K, max length) locally on the device. No data is transmitted anywhere. |

**Remote code:** No — select "I don't use remote code".
